# Cybersecurity Lab Environment Setup

## Task 01 — Cybersecurity and Penetration Testing Lab

This project documents the setup of a controlled cybersecurity laboratory using Oracle VirtualBox and Kali Linux.

## Environment

- Host OS: Windows 10/11
- Hypervisor: Oracle VirtualBox
- Security OS: Kali Linux
- Network: NAT Network
- Network Range: 10.0.0.0/24
- Kali IP: 10.0.0.2/24
- Gateway: 10.0.0.1
- DNS: 8.8.8.8

## Objectives

- Configure VirtualBox
- Install Kali Linux
- Create a NAT Network
- Configure Kali Linux networking
- Verify network connectivity
- Create a clean VM snapshot

## Project

The laboratory provides a controlled environment for practicing cybersecurity, ethical hacking, network reconnaissance, vulnerability assessment, and penetration-testing techniques.

All testing is intended for authorized laboratory environments only.
